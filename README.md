# mini_word_guessing_game

## Overview

This is a simple word guessing game that challenges players to guess a word 
within a certain range(default = 5). Players receive feedback/clues based on 
the number of sequential, correct letters, and the game continues until they guess the correct word.
User is given an option to choose a length of a word and a criteria i.e animal kingdom, fruit, car etc...

## Features

- Interactive gameplay
- Feedback on guesses (based on letters -> does guess contain consecutive numbers that match the secret)
- Configurable range for the word to be guessed
- Basic scoring mechanism
- User-friendly interface

## How to Play

1. Start the game by pressing the "Start" button.
2. Enter your desired word length
3. Select criteria/domain of word
4. After each guess, receive feedback based on sequential accuracy.
5. Continue guessing until you find the correct word!

## Setup

To run this game locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/Pluggamaro/mini_word_guessing_game.git
   ```
2. Navigate into the project directory:
   ```bash
   cd mini_word_guessing_game
   ```
